# Disney Lorcana Complete Set History & Analysis (FR)

Comprehensive guide detailing the evolution of Disney Lorcana from The First Chapter to the current Set 13 and upcoming Set 14.

---

## 1. Set 1: The First Chapter (August 2023)
- **Release**: August 2023
- **Lore Narrative**: Illumineers awaken within The Great Illuminary to harness magical ink.
- **Mechanics**: Shift, Bodyguard, Evasive, Rush, Ward, Support, Singer, Challenger.
- **Key Cards**: *Elsa - Spirit of Winter*, *Tinker Bell - Giant Fairy*, *Maleficent - Dragon*, *A Whole New World*, *Be Prepared*, *Stitch - Carefree Surfer*.
- **Collectibility**: Introduction of the original 12 Enchanted rare cards.

---

## 2. Set 2: Rise of the Floodborn (November 2023)
- **Mechanics**: **Resist +X** damage mitigation.
- **Staples**: *Madam Mim - Fox*, *Merlin - Rabbit / Goat*, *Cinderella - Stouthearted*.

---

## 3. Set 3: Into the Inklands (February 2024)
- **Mechanics**: **Location Cards** with passive lore gain and move costs.
- **Staples**: *Robin Hood - Champion of Sherwood*, *Jafar - Striking Illusionist*, *The Queen's Castle*.

---

## 4. Set 4: Ursula's Return (May 2024)
- **Mechanics**: **Sing Together** cooperative song casting; Illumineer's Quest co-op.
- **Staples**: *Diablo - Devoted Herald*, *Sisu - Emboldened Warrior*.

---

## 5. Set 5 to 12 Overview (2024 - 2026)
- *Shimmering Skies*, *Azurite Sea*, *Archazia's Island*, *Reign of Chaos*, *Fables of Light*, *Whispers of the Deep*, *Sunken Realms*, *Wilds Unknown*.

---

## 6. Set 13: Attack of the Vine! (July 2026 - Current Meta)
- **New Mechanic**: **Duo Shift** (playing high-tier Floodborn cards over two named characters for 0 or reduced cost).
- **Tournament Analytics (111 Tournaments, 14,240 Matches)**:
  - **Tier 1**: Emerald/Steel Discard (54.8% WR), Amber/Steel Steelsongs (53.9% WR).
  - **Tier 1.5**: Ruby/Sapphire Ramp (52.4% WR), Sapphire/Steel Items (51.8% WR).
  - **Tier 2**: Emerald/Sapphire Duo Shift (50.5% WR), Amethyst/Ruby Bounce (49.6% WR).

---

## 7. Set 14: Hyperia City (Releasing October 23, 2026)
- Futuristic urban city setting, new modular cards and anti-discard mechanics.
