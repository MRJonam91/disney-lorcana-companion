# Asset provenance / Provenienza degli asset

The website ships no raster images, videos, card scans, logos, web fonts or
third-party binary assets. Decorative orbs, gradients, bars and card panels
are CSS authored in this repository. Emoji are Unicode characters rendered
by the visitor's operating system; their platform artwork is not bundled.

Il sito non distribuisce immagini, video, scansioni di carte, loghi, web font
o binari di terzi. Sfere, gradienti, barre e pannelli sono realizzati in CSS
nel repository. Le emoji vengono disegnate dal sistema del visitatore:
le relative immagini di piattaforma non sono incluse nel progetto.

Names, character references and game terminology retain their owners'
rights. Before adding assets, record the creator, original URL, explicit
license and any modifications here. A disclaimer is not permission to reuse
protected artwork. / Un disclaimer non autorizza il riuso di opere protette.
