# Support / Assistenza

For site bugs and translation errors, open an issue with the page URL,
browser, viewport and reproduction steps. Use
[Discussions](https://github.com/MRJonam91/disney-lorcana-companion/discussions)
for community questions when enabled. Maintainers provide voluntary support.

Per errori del sito e traduzioni apri una issue con pagina, browser,
dimensione dello schermo e passaggi per riprodurre il problema.
L'assistenza dei manutentori è volontaria.

For current game rulings, legal cards, releases and tournament policy, use
the [official resources](https://disneylorcana.com/en/resources/).
This project does not provide authoritative rulings or purchase advice.
