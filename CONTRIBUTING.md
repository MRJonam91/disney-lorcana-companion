# Contributing / Contribuire

Keep changes focused. Report the observed issue, reproduction steps and the
affected language. Update Italian and English instructions together; do not
claim that partially translated pages are complete translations.

Mantieni le modifiche mirate. Indica problema, passaggi per riprodurlo e
lingua interessata. Aggiorna insieme le istruzioni italiane e inglesi.

Before opening a pull request / Prima di aprire una pull request:

```sh
python tools/check_site.py
node --test tools/odds.test.cjs
```

Open the hub and guides on desktop and a narrow screen. Check navigation,
glossary, tracker, invalid calculator input, keyboard focus and offline use.
The five standalone guides intentionally embed the same runtime; update
every copy. Add an independent regression case for probability changes.

Per i contenuti di gioco cita una fonte primaria, con data e contesto.
Separate official facts, assumptions and community opinions. Do not invent
match counts, simulations, pull rates, prices or card abilities.

By submitting a contribution you confirm that you have the right to submit
it and license your original contribution under this repository's MIT
license. Do not submit third-party artwork, copied rulebooks, secrets or
personal data without applicable permission. / Inviando un contributo
confermi di averne i diritti e di concederlo secondo la licenza MIT del repo.
