# Security / Sicurezza

This is a static educational website: no accounts, backend, payments,
telemetry or server-side data storage. The current tools keep game state
in memory; reloading a guide clears the scores.

È un sito statico didattico: nessun account, backend, pagamento, telemetria
o archivio sul server. I punteggi restano in memoria e si azzerano al ricaricamento.

For a vulnerability, use the repository's **Security → Report a vulnerability**
if available. If private reporting is unavailable, open a public issue asking
for a private contact without including exploit details, personal data or
secrets. Do not post credentials or confidential logs. No response-time
guarantee or bug bounty is offered.

Per una vulnerabilità usa la segnalazione privata GitHub, se disponibile.
Altrimenti chiedi un contatto privato tramite issue, senza pubblicare dettagli
di sfruttamento o dati riservati. Nessuna scadenza di risposta è garantita.
